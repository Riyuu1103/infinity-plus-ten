一本 63 页的数学讲义：从 ZFC 十条公理、空集造数，一路到基数/序数算术、阿列夫层级、选择公理与连续统假设，最后接回数学专业本科课程（数分、线代、抽代、实变、复变、ODE 各自假设了什么）。

## 这本书在回答什么

一个孩子问“无穷大加十等于多少”。答案取决于你说的“无穷大”是哪一种：

| 你问的是 | 对象 | ∞ + 10 |
|---|---|---|
| 有多少 | 基数 ℵ₀ | = ℵ₀（不变） |
| 排到哪 | 序数 ω | > ω（变长） |
| 当数算 | 超实数 ω | > ω（变大，仍是数） |

## 结构

1. 第一编 地基：逻辑与 ZFC 十条公理、关系/函数/序
2. 第二编 造数：ℕ → ℤ → ℚ → ℝ → ℂ，实数完备性的七张脸
3. 第三编 无穷的算术：等势、对角线、基数算术、序数与超限归纳、阿列夫层级、选择公理、连续统假设、大基数
4. 第四编 与大学数学专业课程的关系
5. 第五编 补遗定理；第六编 全景回顾
6. 附录：ZFC 公理表、符号表、19 本书目、年表、二十个常见误解
